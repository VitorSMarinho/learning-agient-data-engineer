# Critérios de Aceite — Módulo 13

## Obrigatórios (bloqueiam aprovação)

- [ ] Dashboard roda local com um comando documentado, sem passo manual extra não documentado.
- [ ] Existem exatamente as 3 visualizações pedidas, cada uma respondendo um tipo diferente de
  pergunta (comparação, tendência, distribuição) — não é o mesmo tipo de gráfico repetido 3x.
- [ ] Pelo menos 1 filtro interativo funcional (muda o dado exibido de verdade, testável
  manualmente).
- [ ] `POR_QUE_ESSE_GRAFICO.md` justifica cada escolha de gráfico de forma específica pra
  pergunta (não genérico tipo "porque fica bonito").
- [ ] Evidência visual real (print ou gif) da entrega, não só código sem nunca ter rodado.

## Opcionais (nota, não bloqueiam)

- [ ] Agregação pré-calculada em vez de on-the-fly, com justificativa de performance.
- [ ] Responsividade (funciona em tela menor).
- [ ] Mais de 1 filtro combinável.

**Veredito final**: `aprovado` se os 5 itens obrigatórios atendem; `precisa_ajuste` caso contrário.
