# Learning Agient — Engenharia de Dados

Trilha de estudo autoconduzida pela marca Agient, construída em torno do **Método Agient**:
cada módulo entrega um projeto real, revisado por um subagente especialista de código (não
teoria consumida passivamente, não videoaula). O critério de "concluído" é um projeto que
funciona e passa pelos critérios de aceite do módulo, avaliado com o mesmo rigor de um code
review de verdade.

Como funciona um módulo: leia o `README.md`, estude os recursos gratuitos listados, resolva o
projeto em `projeto/` seguindo `ENUNCIADO.md`, abra um PR com a solução, rode a revisão. O
resultado fica registrado em `reviews/<modulo>.json` e reflete automaticamente na plataforma
[learning-agient](https://github.com/VitorSMarinho/learning-agient).

Pipelines robustos e escaláveis para produção.
